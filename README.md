# My NixOS configuration files
These are configuration files for NixOS 24.11. `./setup.sh /path/to/disk` should install NixOS 24.11 using my configs, although this script is best suited to installing it to a VirtualBox machine without EFI. e.g. if you want to install in a VirtualBox machine to `/dev/sda`, `./setup.sh /dev/sda` should do it.
